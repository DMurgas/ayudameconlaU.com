ÚSALA BIEN

La IA ayuda. El aprendizaje sigue siendo tuyo.

Utiliza estas herramientas para comprender y practicar, no solamente para obtener respuestas.

✓

Comprende: pide explicaciones, ejemplos y procedimientos.

✓

Practica: genera preguntas y ejercicios antes de una evaluación.

✓

Verifica: contrasta información importante con fuentes académicas.

✓

Protege: evita introducir datos personales o información académica confidencial.
